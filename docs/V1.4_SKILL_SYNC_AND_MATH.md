# v1.4 기존 Skill 동기화 및 HTML 수식 렌더링 수정

## 1. 누락 원인

`korean-engineering-mcp`는 두 개의 독립 배포 계층을 사용합니다.

1. MCP 실행 패키지: 도구 구현과 스키마를 제공
2. 클라이언트 Skill: 근거 우선 답변, HTML opt-in 질문, 동일 본문 전달 정책을 제공

기존 업데이트 절차는 MCP 코드·도구 연결만 새로 확인하고 이미 `~/.hermes/skills/` 등에 복사된 Skill을 다시 동기화하도록 강제하지 않았습니다. 따라서 MCP에서 `render_engineering_answer_html` 도구 15개가 정상 노출되어도 클라이언트가 이전 Skill을 계속 읽으면 `동일 내용의 HTML 보고서도 생성할까요?` 질문이 누락될 수 있었습니다.

추가로 guided installer가 일부 Skill 설치 실패를 `|| true`로 무시해 업데이트 실패가 성공처럼 지나갈 수 있었습니다.

## 2. 기존 Skill 업데이트 수정

- `scripts/sync-skill.mjs` 관리형 동기화 도구 추가
- npm bin `korean-engineering-mcp-sync-skill` 제공
- Hermes, Claude, Antigravity 대상 지원
- 설치본과 번들 Skill의 디렉터리 SHA-256 비교
- 동일하면 `unchanged`로 종료
- 다르면 기존 Skill 전체를 별도 백업한 뒤 교체
- staging, backup, 최종 설치본 해시 검증
- 대상 Skill 디렉터리 심볼릭 링크 거부
- 동기화 오류를 non-zero로 반환하고 guided installer가 더 이상 무시하지 않음
- `install-hermes.sh`와 `install-skill.sh`를 신규 설치/업데이트 공용 경로로 통합

명시적 업데이트 명령:

```bash
npm exec --yes --package=github:sonmeggy/korean-engineering-mcp -- \
  korean-engineering-mcp-sync-skill hermes
```

MCP package 설치만으로 사용자 홈을 자동 변경하는 `postinstall`은 사용하지 않습니다. 클라이언트 Skill 변경은 위 명시적 동기화 명령에서만 수행합니다.

## 3. HTML 수식 렌더링 수정

기존 `markdown-it` 기본 설정은 TeX 수식을 해석하지 않아 Telegram에서 표시되던 `$...$`, `$$...$$`가 HTML에서는 일반 문자열로 남았습니다.

v1.4에서는 다음과 같이 수정했습니다.

- KaTeX를 서버측 파서로 사용
- 인라인 `$Q = A v$` 지원
- 블록 `$$h_f = f \\frac{L}{D} \\frac{v^2}{2g}$$` 지원
- 결과는 외부 CSS·JavaScript·폰트가 필요 없는 MathML만 출력
- `trust=false`, `throwOnError=false`, `maxExpand=1000`, `maxSize=50` 적용
- 수식 원문을 `data-tex`에 보존해 plain-text 복사 시 TeX로 복원
- A4 인쇄/PDF 및 표 안 수식 스타일 추가
- 원격 MathJax/KaTeX script를 추가하지 않고 기존 CSP 유지

## 4. 검증 항목

- HTML opt-in 정책 문구가 업데이트된 Skill에 존재
- 기존 설치본 업데이트 시 백업 1건 생성 및 source/installed SHA-256 일치
- 동일 버전 재실행 시 `unchanged`, 추가 백업 없음
- npm package의 bin symlink를 통한 실제 CLI 실행
- Node.js 18/20/22에서 동일한 33개 테스트 통과
- MCP stdio 도구 discovery와 HTML 도구 호출
- 동의 전 `user_confirmation_required`, 파일 미생성
- 인라인·블록·표 안 TeX가 `<math>` MathML로 변환
- `javascript:` 수식 명령이 실행 가능한 링크를 만들지 않음
- raw HTML, 비 HTTPS 링크, 외부 이미지 차단 정책 유지
- Chromium 실제 화면, A4 PDF 2페이지 렌더링에서 수식·표의 겹침/잘림 없음
- package archive에 Skill, sync CLI, math renderer, HTML template 포함

## 5. 업데이트 후 적용

Hermes에서 Skill과 MCP를 갱신한 뒤 현재 실행 프로세스가 새 내용을 다시 읽도록 처리해야 합니다.

- Skill: 새 세션 또는 `/reload-skills`
- MCP: `/reload-mcp`
- 검증: `hermes mcp test <등록된-server-name>`에서 15개 도구와 `render_engineering_answer_html` 확인
